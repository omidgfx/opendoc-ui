For developers

The engineering story: a deliberately small stack, a rigorously tested core, and a repository organized so a newcomer can find their way in an afternoon.

The stack

Deliberately conventional, rigorously verified

TypeScript + React 19

The entire application is typed end to end. Components are organized by surface — endpoint views, schema exploration, notes, AI — with shared hooks for routing, theming and persistence.

Vite 6

One deliberately inlined production bundle (dist/index.js) so static deployments never worry about chunk filenames. A single-bundle verification script guards the invariant on every build.

Tailwind 4 + Phosphor

Utility-first styling with a CSS-variable theming system, and the Phosphor icon set throughout the interface.

Monaco Editor

The industry-standard editor powers raw JSON bodies, schema inspection and code viewing.

@scalar/openapi-parser

Optional engine validation and external reference resolution, with errors surfaced as scoped diagnostics rather than fatal failures.

IndexedDB-first persistence

Specifications, response history, notes, panel widths and workspace state persist through a resilient storage layer with a localStorage fallback.

Repository layout

Where everything lives

PathContents
src/The application — components, hooks, contexts, pages, types and utilities
src/utils/openapi/The OpenAPI engine: parsing, normalization, validation, references, serialization and capabilities
src/utils/runner/Request planning, execution, response handling and the recursive body form logic
server/The hardened AI gateway (ai-gateway.ts) and its policy module
downloaders/ · ai-gateways/Spec downloader and AI gateway reference implementations in six and nine frameworks
scripts/Build support: SPA fallback, single-bundle verification, UI contracts, the builder CLI
tests/Unit suites plus the Playwright browser suite
docker/ · site/Docker packaging (Dockerfile, nginx, compose helpers) and this website
Quality gates

One command runs everything

npm scripts
npm run dev          # development server on :3000
npm run build        # production bundle + SPA fallback + single-bundle verification
npm run lint         # prettier, tsc --noEmit, UI contract checks
npm test             # unit suites: run, serialization, swagger2, async, conformance
npm run test:browser # Playwright browser suite
npm run test:all     # everything above, in order
npm run make         # the guided builder CLI

The test suite covers the OpenAPI normalization matrix, parameter serialization across all styles, Swagger 2.0 adapters, the AI gateway policy, runner execution against a real HTTP recorder, recursive schema rendering, local notes workflows, navigation history and UI contracts (custom selects and tooltips). The browser suite additionally audits accessibility with axe-core.

Contributions are welcome. Open an issue first for anything substantial, keep the existing formatting (Prettier with 120 columns), and make sure npm run test:all passes locally before opening a pull request.
