Frequently asked questions

Straight answers to the questions that come up most — about privacy, architecture, the AI assistant, and where everything lives.

Does OpenDoc UI require a backend server?

No. The documentation browser, the Runner, the schema explorer, notes, theming and code generation all run entirely in the browser. The only optional server components are the AI gateway (for teams that want provider keys server-side) and the downloader proxy (for fetching remote specifications across restrictive networks) — both are opt-in.

Are my specifications uploaded anywhere?

Never. Local files are parsed in the browser and stored only in your browser's local history. Nothing is uploaded, and the original document is never modified. When you load a remote URL, the browser fetches it directly (or through a proxy you configured) — no third party is involved.

Which OpenAPI versions are supported?

OpenAPI 3.0, 3.1 and 3.2, plus Swagger 2.0, in YAML or JSON. Modern 3.1/3.2 keywords — const, prefixItems, unevaluatedProperties, if/then/else, type unions, webhooks — are rendered and handled explicitly. Multi-file reference graphs resolve in memory.

Does the Runner send requests from my browser?

Yes — that is the point. Requests are composed from the specification and executed with the browser's fetch API against the server you select, so you can test real authentication, parameters and bodies without leaving the documentation. The same CORS rules that apply to any web application apply here, and the Runner Compatibility report states what the browser can and cannot do for a given API.

How does the AI assistant work, and where do my keys go?

The assistant receives redacted endpoint and schema context from your open specification and answers with citations. In direct mode, your browser talks to the provider you configure (OpenAI, Anthropic, Ollama, OpenRouter or any compatible endpoint). In gateway mode, a hardened server gateway owns the provider credentials and enforces token authentication, origin allowlists, rate limits and timeouts — the browser never sees the provider key.

Can I run it on an internal network without internet access?

Yes. The application is fully static — copy dist/ to an internal nginx or Apache host, or use the Docker image, and it works offline. Configured specifications can be baked in through config.json or window.INITIAL_CONFIG, and local files always work. The only components that need the internet are the optional AI provider and remote-spec downloads.

What happens to my notes if an endpoint is renamed or removed?

Notes follow the endpoint through the specification's lifecycle. When an endpoint disappears, its notes move to the Orphaned list, where you can re-assign them to another endpoint or delete them deliberately. Deleting a note always goes to the Trash first — restore, permanent delete and empty-trash are available, so nothing is lost by accident.

Can I share what I am looking at?

Everything is deep-linkable: endpoint tabs, response codes, schema modals and search states are encoded in the URL. Send a link and the recipient lands on exactly the same view. This also means browser back and forward work naturally across the whole workspace.

Where is the live demo, and where is this website hosted?

The live application runs at /demo/ on this site and is deployed to GitHub Pages from the repository's master branch on every push — it is always the latest build. This website lives at the site root of the same deployment, and the source of both is the opendoc-ui repository.

How do I deploy my own instance?

Three comfortable paths: copy dist/ to any static host; use docker compose up --build -d; or run npm run make and let the guided builder ask about your deployment preferences, produce a verified build, and offer to start it. The deployment guide walks through all of them.

Is OpenDoc UI free?

Yes — it is open source under the MIT License. Use it, modify it, embed it, and ship it commercially. Attribution is appreciated, and the project lives on GitHub, where issues and contributions are welcome.
