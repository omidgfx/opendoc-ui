Capabilities

A complete API workstation, in one interface

Open a specification once and every surface you need appears: read it, understand it, call it, generate against it, and keep notes beside it — without ever leaving the document.

Documentation browser

Tag-based endpoint navigation with method badges, route display and protection indicators. Every operation renders its parameters, request bodies and response matrices with rich schema tables, examples, enum values and a built-in pattern tester — recursive and composed schemas handled safely.

Explore the documentation surface

Built-in API Runner

Compose real requests with path, query, header and cookie parameters, JSON or raw bodies, multipart file uploads and full authentication — bearer, API keys, basic auth and OAuth. Execute from the browser and inspect status, headers, body and history, with response cancellation.

See the runner in action

Schema explorer

Browse every model in components/schemas with search and letter filters, drill into referenced schemas, and inspect allOf/oneOf/anyOf/discriminator composition safely. Generate simulated example objects per media type and export any schema as TypeScript.

Dive into the schema matrix

Code & type generation

Ready-to-run request snippets in curl, JavaScript fetch and axios, Python, Go, C#, PHP and Angular — with secrets automatically redacted into placeholders. Export the entire schema set as TypeScript models plus example constants, as a ZIP or a single file.

See generated code

Local notes & todos

Spec-scoped Markdown notes and todos with fourteen theme-safe tones. Todos can auto-hide endpoints when complete. A full trash with restore, an orphaned-notes list for renamed or removed endpoints, and JSON export/import — nothing is ever lost by accident.

Understand the notes workspace

Optional AI assistant

Ask grounded questions about your API with citations, and let the assistant open endpoints, fill the Runner and prepare requests through a safe action bridge. Connect directly to OpenAI, Anthropic, Ollama or OpenRouter — or run a hardened server-side gateway.

Learn about the assistant
Workflow

From specification to shipped integration in three deliberate steps

01 · OPEN

Open a specification

Choose a local JSON or YAML file from your device, load a remote URL, or ship pre-configured specifications inside your own deployment. Multi-file references resolve in-memory, and your source document is never modified.

02 · EXPLORE

Explore with confidence

Navigate every endpoint, inspect every schema, generate examples and TypeScript, and verify patterns against real constraints. Deep links preserve exactly what you are looking at — shareable with anyone.

03 · INTEGRATE

Test, integrate, share

Execute authenticated requests against real servers, copy production-ready snippets into your stack, keep notes beside the endpoints you own, and export everything you need for your team.
